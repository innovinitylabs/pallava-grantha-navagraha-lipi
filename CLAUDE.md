# Nava Graha Lipi

An open-source Indian astronomical glyph initiative rooted in Tamil-region epigraphical traditions.

## Mandatory Language & Script Policy

**ONLY TWO LANGUAGES ARE PERMITTED IN THIS PROJECT:**
1. **Tamil** (Historical Tamil-region scripts: Pallava Grantha, Vatteluttu, Tamil-Brahmi, and Modern Tamil).
2. **English** (with standard academic Latin IAST transliteration).

**STRICT PROHIBITION:**
- **No Hindi or Devanagari script anywhere in code, data, UI, or docs.**
- **No other modern Indian languages.**

## Technology Stack

- **Stack**: Next.js 16 (App Router), React 19, TypeScript, Tailwind CSS v4, Framer Motion.
- **Conventions**: Replicates the exact technology stack, paper material system, and component architecture of Anekaroopam (`/Users/valipokkann/Developer/projects/anekaroopam-site`).
- **Typography**: Cormorant Garamond (Display), Source Serif 4 (Body), Anek Tamil (Tamil script).
- **Build**: `npm run build` (`next build --webpack`).
- **Domain**: `nava-graha-lipi.valipokkann.in`
